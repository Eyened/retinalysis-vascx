## Bifurcation features

### Bifurcation

Computed combinations:

- Computed in the full region of a cropped circular grid centered nine-tenths of the way from the optic disc to the fovea, with radius equal to nine-tenths of their separation plus the optic-disc radius. Parameters: center=0.9; radius multiplier=0.9; band crop fraction=0.12. arteries: `bif_angle_mean_crcl_arteries`; arteries: `bif_branching_coefficient_mean_crcl_arteries`; arteries: `bif_jed_mean_crcl_arteries`; arteries: `bif_count_crcl_arteries`; veins: `bif_angle_mean_crcl_veins`; veins: `bif_branching_coefficient_mean_crcl_veins`; veins: `bif_jed_mean_crcl_veins`; veins: `bif_count_crcl_veins`.

Components:

| Component | Units | Description |
| --- | --- | --- |
| `angle_mean` | degrees | Arithmetic mean of eligible daughter–daughter opening angles. |
| `branching_coefficient_mean` | dimensionless | Mean of (d1²+d2²)/d0² per eligible bifurcation, using whole-segment mean diameters; d0 is the parent. |
| `jed_mean` | dimensionless | Mean absolute cubic junctional exponent deviation: cuberoot(abs(d0³-d1³-d2³))/d0. Zero satisfies Murray's law. Uses whole-segment mean diameters, not a fitted exponent. |
| `count` | count | Number passing region, daughter-length and angle filters, including nodes without valid diameter measurements. Reported even below the minimum required for means. |

## Optic disc morphology

### Optic disc

Computed combinations:

- Measured on the optic disc relative to the processed image’s top-left origin; coordinates do not anatomically align images. retina: `od_valid`; retina: `od_fraction_outside_bounds`; retina: `od_centroid_x`; retina: `od_centroid_y`; retina: `od_fovea_distance`; retina: `od_ellipse_a`; retina: `od_ellipse_b`; retina: `od_ovality_index`; retina: `od_circularity`; retina: `od_area`; retina: `od_area_norm`; retina: `od_torsion`.

Components:

| Component | Units | Description |
| --- | --- | --- |
| `valid` | dimensionless | 1 if VascX accepted an optic-disc ellipse, otherwise 0; always reported. |
| `fraction_outside_bounds` | fraction | Fraction of reconstructed ellipse area outside the fundus ROI or image; 0 is fully visible. |
| `centroid_x` | px | Fitted ellipse centroid x (column) coordinate from the processed image’s top-left origin; estimated from the visible contour when fraction outside bounds > 0. |
| `centroid_y` | px | Fitted ellipse centroid y (row) coordinate from the processed image’s top-left origin; estimated from the visible contour when fraction outside bounds > 0. |
| `fovea_distance` | px | Euclidean distance from the fitted ellipse centroid to the fovea, if available. Estimated when fraction outside bounds > 0. |
| `ellipse_a` | px | Semi-major axis length of the fitted ellipse; reported only for fully visible discs. |
| `ellipse_b` | px | Semi-minor axis length of the fitted ellipse; reported only for fully visible discs. |
| `ovality_index` | dimensionless | Semi-major / semi-minor axis ratio (a/b); 1 is circular. Reported only for fully visible discs. |
| `circularity` | dimensionless | 4*pi*A/P^2 from the cleaned disc segmentation's pixel area A and four-direction Crofton perimeter P. Approximately 1 for a circle; discretization can give values slightly above 1. Reported only for fully visible discs. |
| `area` | px² | Area of the cleaned optic-disc segmentation, natively counted in pixels; reported only for fully visible discs. |
| `area_norm` | dimensionless | Segmentation area divided by squared centroid–fovea distance; requires a fully visible disc and a finite, nonzero distance. |
| `torsion` | degrees | Unsigned acute angle (0–90 degrees) between the ellipse major axis and the perpendicular to the centroid–fovea vector. Requires a fully visible disc, a distinct fovea, and unequal ellipse axes; orientation is unstable for near-circular discs. |
