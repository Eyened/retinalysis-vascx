# VascX documentation website

```bash
npm ci
npm run build
npm run serve
```

This site builds independently from committed public assets and the repository
README. Python, Rotterdam data, and sibling projects are not required.
`npm run content:generate` partitions the README using `content-map.json`.
`npm run content:validate` checks source fidelity and generated asset hashes.

Reliability pages, aggregates, and selected explanation grids are generated by
the external `docs_vascx` project in the internal workspace. Regenerate them
there; do not hand-edit files recorded in `generated-assets.json`.

Validation:

```bash
npm test
npx playwright install chromium
npm run test:browser
```

The Documentation workflow builds pull requests and deploys successful `main`
builds to https://eyened.github.io/retinalysis-vascx/ using GitHub Pages Actions.
For first deployment, set the repository's Pages source to **GitHub Actions**.
The `github-pages` environment must allow deployment from `main`.
